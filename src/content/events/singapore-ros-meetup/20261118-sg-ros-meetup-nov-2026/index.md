**Talks:**
**1.** Intrinsic Core: An open source approach to Physical AI
Speaker: **Aaron Chong (Mobility Lead, Intrinsic)**
With the goal of democratizing access to intelligent robotics, the core parts of the Intrinsic platform have been released under the Apache 2.0 license at ROSCON 2026, along with a reference [Open Machine Tending Solution (OMTS).](https://github.com/intrinsic-ai/intrinsic-omts) This talk will give a technical overview of [Intrinsic Core ](https://github.com/intrinsic-ai/intrinsic-core)and OMTS, the motivation and goals behind this effort, as well as what's next for us and the open source robotics community
**2.** Next Generation Open-RMF Prototype
Speaker: **Samuel Foo (Open-RMF GSoC2026 Contributor)**
Multi-robot fleets operating in shared spaces must handle both contention for limited destinations and obstacles that appear after a plan has been issued. We present two extensions to the Open-RMF next-generation prototype that address these challenges.
The first part introduces a [reservation-aware destination server](https://github.com/open-rmf/next_gen_prototype/pull/25) that selects among alternative goals, prevents overlapping assignments, and queues or parks blocked robots.
The second part presents a [layered global occupancy map](https://github.com/open-rmf/next_gen_prototype/pull/36) that combines a static map with short-lived robot observations. It preserves a standard ROS occupancy-grid interface, allowing the planning stack to detect obstacles blocking an active route and request a controlled replan.
