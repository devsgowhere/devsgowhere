🧱 **10.30am - 11.10am : Topic - Using Claude Code to create a website**

Join us for an interactive, live-coding session for non-techies where we dive into the power of Claude Code! Starting with a quick look at a live project, we will break down what Claude Code is, how to use it responsibly and the ethical considerations before handing the steering wheel over to you, the audience. You will vote on the site's theme, and together we will build and deploy a base website live from scratch. The excitement doesn’t stop there—through three interactive voting rounds, you will help shape the site's color palette, features, and even hidden easter eggs in real-time. We will wrap up with a final live deploy of our creation, followed by a Q&A session to show you exactly how you can start building your own projects tonight.

🤖 **11.30am - 12.10pm : Topic - Beyond the System Prompt - Scaling AI capabilities with Agent Skills**

As LLM-powered agents move from simple chat interfaces to complex autonomous systems, developers face a recurring challenge: the "Monolithic Prompt." Cramming every tool, instruction, and piece of documentation into a system prompt leads to high latency, increased costs, and "context lost in the middle." In this session, we explore Agent Skills, an open standard and Python library designed to modularize agent capabilities. We will dive into the architecture of a "Skill"—a structured bundle of Markdown instructions, Python scripts, and reference data—and demonstrate how agents can dynamically discover and load these skills only when needed. You will also learn about how Agent Plugins for AWS equip AI coding agents with the skills to help you architect, deploy, and operate on AWS. Agent plugins for AWS are currently supported by Claude Code, Codex, and Cursor. You will also understand the limitations and ethical considerations when scaling AI capabilities.
