This month, we're going into the latest advances in model training - including Doing It Yourself!

Talks:
**"Cooperation vs Competition" - Martin Andrews**
People are trying to get models to train more effectively by setting up processes that cause models to compete with each other (for instance AlphaZero), or act cooperatively towards a common goal. Martin will go over some of the history - and look at the latest directions.

**"LLM RL Training for Beginners" - Sam Witteveen**
In a this talk, Sam will talk about the different applications of reinforcement learning for LLMs, how you can use them, and how you can get started training Reinforcement Learning on LLMs yourself.
