# Fast Feedback: Continuous Integration You Can Actually Trust

📅 Friday, 30 October 2026  
🕕 6:30 PM – 9:00 PM (doors open at 6:00 PM)

This event continues our 2026 DevOps Journey series. A gate you ignore is not a gate. This night is about CI that is fast enough to trust, and trust you can actually put in the pipeline.

## 🎯 What to Expect

-   🔧 A live demo of splitting and caching E2E so the suite is a gate, not a nightly job
    
-   🤖 A Visa DevOps journey: zero automation → working CI/CD → “smart CI” with GenAI → deployments and a chatbot in Microsoft Teams
    
-   💡 What broke, and how a team built trust in AI-generated changes
    
-   ⚡How to evaluate current capabilities and understand next steps
    
-   🤝 Great networking with builders, indie hackers, and tech leaders embracing agentic workflows

# 🎙️Speakers

## Scaling E2E tests the smart way with Nx

**Vladimir Radzivil, Principal Consultant, Zühlke**  
Making your slowest quality gate fast enough to actually use and trust on every pull request  
Live demo, no AI. Measured ladder:

1.  Example `e2e` tests
    
2.  atomize-but-serial is slower;
    
3.  parallel on the cores you have is the win;
    
4.  more machines only pay once you run out of cores.
    
5.  Join us to learn more
    

## From zero to smart CI

**Deepthi Gururaj, DevOps lead, Operations and Infrastructure, Visa**  
The talk will walk through three stages:

1.  Going from zero automation to a working CI/CD pipeline which alone was a big shift for the org in terms of deployment speed and reliability.
    
2.  This year we’ve been pushing into "smart CI", introducing GenAI into the pipeline itself.
    
3.  Integrated deployments and a DevOps chatbot directly into Microsoft Teams, so developers can do DevOps tasks without leaving the tool they already work in all day.
