**Presentation**
**Topic: How I build a Homelab with Kubernetes v2 - now with AI(tm)**

**Presenter:** Sharon Woo, Software Developer
[https://www.linkedin.com/in/sharon-woo/](https://www.linkedin.com/in/sharon-woo/)

Last year I spoke about how I built my homelab over the years (https://www.youtube.com/watch?v=Dplt1sd1BY8), buying the hardware, installing and maintaining the software manually, for basically no one to use it. I'm still on a single node k3s setup because grandmothers would call me crazy for having 3 computers I don't use instead of 1, ESPECIALLY since the market price of my setup is \*now\* about $6000, ain't nobody got money for 3x of that. The benefit of having a simple set up: I've since integrated coding agents very lightly to help me build and host little personal projects on it faster, improve alerting, update deployments, you name it. It's a great way to stay sharp and current, and it's a benefit of using k8s instead of a docker + bare metal setup.

I have a kid, I have been doing software and data for about 9 years now. Kind of wish I spent my masters degree $ on NVDA on hindsight or joined MU.

**About JuniorDev SG:**
JuniorDev SG is a developer interest group that focuses on providing a place for junior developers to learn and network with each other.
At the same time, we seek to be a support system to help junior developers break into tech, navigate their careers as well growing them to one day become senior developers or tech leaders in the tech industry.
