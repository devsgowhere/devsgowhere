It works on your machine.

It works in Docker.

Now the real fun begins.

This is a free 4-hour hands-on workshop from GeeksHacking on turning a containerised application into a workload running in a Kubernetes cluster.

We won't be sitting through slides. You'll write the resource files yourself, from an empty file, connecting the dots between Pods, Deployments, Services and Gateways — until your application is up and serving traffic in a real cluster.

By the end you'll be able to:

Write a Deployment and understand what the scheduler does with it
Expose a workload with a Service, and explain why you needed one
Route external traffic in through a Gateway
Read a failing pod and work out why it's failing
This is for you if you build web applications and have used Docker. That's it. You don't need a homelab, a cloud account, or a certification. No Kubernetes wizardry required.

Bring: a laptop, Docker running locally, and a container image of your own if you have one. We'll provide a fallback app if you don't.

Come with your container. Leave with a cluster.
